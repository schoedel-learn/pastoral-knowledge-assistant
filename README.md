# Pastoral Knowledge Assistant

A bilingual RAG-based AI chat interface designed to provide 24/7 access to institutional policies, pastoral resources, and information while maintaining appropriate sensitivity levels and human escalation pathways.

## Overview

This system serves as a first-stop information resource that:

- Reduces staff burden from repetitive inquiries
- Provides bilingual accessibility (Spanish/English)
- Maintains pastoral voice and cultural sensitivity
- Implements tiered sensitivity handling for crisis, pastoral, and complex situations
- Ensures accuracy through human review and source citation

## Project Structure

- `/docs` - Requirements, architecture, and implementation documentation
- `/src` - Source code for RAG system, chat interface, and supporting components
- `/tests` - Test suites for quality assurance
- `/scripts` - Setup and deployment automation
- `/config` - Environment-specific configuration

## Key Features

- **Tiered Sensitivity Framework**: Crisis detection, pastoral matter handling, complex policy escalation
- **Bilingual Support**: Full Spanish and English language support with user selection
- **Accuracy Safeguards**: Human review, source citation, feedback mechanisms, regular audits
- **Pastoral Voice**: Warm, culturally sensitive, adaptive to user sophistication
- **Conversation Management**: Session-based context with privacy protection
